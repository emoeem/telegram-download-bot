## 一、这个软件是做什么的

**一句话：它把你 Telegram 里看到的内容，实时复制一份到你自己手机里，从此那些内容归你保管。**

Telegram 的消息存在别人的服务器上。发消息的人可以撤回，群管理员可以删除，频道可以清空——
这些动作对**服务器上**的那一份是有效的，对**你手机里的那一份**没有影响。

这个软件做的就是那个「另一份」：

| 你平时的遭遇 | 装了这个软件之后 |
|---|---|
| 对方发了资料，你还没看完就撤回了 | 撤回前已经存下，随时能翻出来 |
| 群里的干货被管理员删了 | 「已删除」视图里还在，图片视频都能打开 |
| 一条消息被改了三次，你不知道原来写的什么 | 「编辑记录」里三个版本按时间排好 |
| 频道清空跑路，几个月的内容全没了 | 你本地一份完整，还能导出 |

## 二、核心特色：撤回和删除，对它无效

这是这个软件和「截图保存」「转发给自己」最本质的区别。

### 2.1 它是怎么做到的

不是录屏，不是定时截图，而是**接在 Telegram 的协议层上**：

1. **消息到达**
   你的账号收到消息的那一刻（不是你点开的那一刻），软件就已经拿到全文和媒体。
2. **立刻落地**
   文字写进本地数据库；图片 / 视频 / 文件下载成真实文件，按内容指纹去重存好。
3. **撤回只是一个标记**
   对方撤回后，Telegram 通知你的账号「这条没了」。软件收到通知，做的不是删除，
   而是在自己库里打一个「已删除」的标记：**正文不动、媒体文件不动、时间戳不动**。

所以「撤回」在软件里不是丢失，而是**多了一个标签**。

### 2.2 你能亲眼看到的证据

- 左侧导航有一栏 **「⚠ 已删除」**，点进去就是所有被撤回/删除的消息
- 打开任意一条被删的消息，顶部会有一条横幅：**「⚠ 已从 Telegram 删除，本地档案保留」**
- 那条消息的图片、视频、文件仍然可以正常打开、下载、导出

实测样本：撤回后的 6 条消息，原文全部在库，媒体文件的 sha256 与撤回前**逐字节一致**。

### 2.3 必须说清的边界（不吹牛）

| 情况 | 能不能留 |
|---|---|
| 软件在运行、账号在线时发的消息，之后被撤回 | **能**，原文和媒体都在 |
| 消息发出来时你的账号**不在线**，等你上线时已被删除 | 收不到。协议层不会补发已删内容 |
| 私密聊天（端到端加密的 Secret Chat） | 不支持，这类聊天不经过普通归档通道 |
| 一次性查看的「闪照」 | 取决于发送方设置，可能拿不到原图 |
| 你自己主动「清空归档」 | 会真删。这是唯一会丢数据的操作，有二次确认 |

**所以它的价值在于「持续在线」**：让它一直挂着，比什么都重要。

## 三、功能一览

| 功能 | 说明 |
|---|---|
| **实时归档** | 监控的聊天/频道/群组，新消息即时入库，媒体自动下载 |
| **历史回填** | 添加监控源时可指定回溯范围和条数，把过去的内容也抓下来 |
| **已删除视图** | 被撤回/删除的消息集中查看，含媒体 |
| **编辑记录** | 每条消息的每次修改都留一个版本，可对比 |
| **全站搜索** | 中文、英文、中英混排都能搜，支持 `from:@某人` `has:image` `before:日期` 等语法 |
| **分类浏览** | 消息 / 图片 / 视频 / 文件 / 链接 分开看 |
| **论坛话题** | 话题群组按话题筛选 |
| **编号收件箱** | 每个收到的媒体自动编号，按编号查、取、发 |
| **导出** | 任意视图导出 CSV / JSON；也能导出成 Telegram Desktop 格式 |
| **通知规则** | 关键词命中就推送到 Webhook 或另一个 Bot |
| **自动点击** | 频道里的按钮和 `t.me` 链接可由账号自动处理并回传结果 |
| **本地存储** | 全部数据在你自己手机里，不上传任何第三方服务器 |

## 四、上手四步

### 第 1 步：安装

拿到 APK 文件（`TG归档-Android-arm64-x.x.x.apk`），传到手机上点击安装。
系统提示「未知来源」时选允许——这是自己签名的软件，没有走应用商店。

> 安装包只支持 **arm64**（近几年的安卓手机都是）。安卓 8.0 以上。

### 第 2 步：激活（只做一次）

打开 App，第一屏不是主界面，而是**激活页**：

| 屏幕上显示 | 这一行是什么意思 |
|---|---|
| 本机尚未授权 | 还没激活，正常，接着往下做 |
| 设备码　`CT84B4MD` | **把这 8 位发给提供软件的人** |
| `[ 输入密钥 ]` | 收到密钥后粘贴到这里 |
| `[ 激活 ]` | 点它 |

> 设备码每台手机不一样，以你自己屏幕上显示的为准，上面这串只是例子。

1. 把**设备码**（8 位字母数字）发给卖你软件的人
2. 对方回你一串密钥，形如 `MF7TH6NK-222C8PKD-2TYRNSC3-THMCNGSF-2H5SPB6G`
3. 粘贴进输入框，点「激活」

激活成功后直接进主界面，以后不用再输。

> **为什么必须给设备码**：一把密钥只对应一台手机。这样即使密钥被别人看到，也没法在他手机上用。
> 换手机时需要重新申请。

### 第 3 步：登录 Telegram 账号

主界面右上角有一个灰色小标签（显示「未登录」），点它：

- **扫码**（推荐）：用你手机上的 Telegram → 设置 → 设备 → 链接桌面设备，扫屏幕上的二维码
- **手机号**：输 +86 开头号码，验证码会发到你已登录的 Telegram 设备上
- **Session**：已经有 Telethon 的 session 字符串时可直接粘贴

> ⚠️ 这里登录的是**你自己的 Telegram 账号**，不是机器人。
> 软件只是用你的账号「看」，不会替你做任何发消息、加群、改资料的动作。
> 开了两步验证的账号，扫码后还会要你输一次云密码。

### 第 4 步：添加监控源

左侧栏底部「监控源」→ 点 **「＋ 添加源」**，填：

| 字段 | 填什么 |
|---|---|
| 目标 | `@频道用户名`、`t.me/xxx` 链接、或数字 chat id |
| 回溯条数 | 想把过去多少条也抓下来，例如 `1000`（0 = 只收新消息） |
| 回溯起点 | 可选，例如 `2026-01-01` |
| 下载媒体 | 建议开，否则只存文字 |

保存后后台开始回填，右栏「下载」面板能看到进度。

**把你关心的频道、群、私聊都加进来。** 加得越全，能救回来的越多。

## 五、日常怎么用

### 5.1 左侧导航

| 视图 | 用途 |
|---|---|
| ▤ 消息 | 全部消息时间线，按监控源筛选 |
| ▧ 图片 / ▶ 视频 / □ 文件 | 按媒体类型浏览 |
| ↗ 链接 | 所有出现过的链接，按域名归类 |
| **⚠ 已删除** | 被撤回或删除的内容 |
| **✎ 编辑记录** | 改过的消息，每次修改都在 |
| ⚙ 发布目标 | 配置把内容转发到别的频道 |
| ▦ 材料 | 媒体素材库 |
| # 编号 | 编号收件箱（按编号查文件） |
| ▣ 存储 | 数据库/媒体/备份占多少空间 |

### 5.2 搜索

顶部搜索框支持这些写法，可以组合：

| 写法 | 意思 |
|---|---|
| `合同` | 普通关键词 |
| `from:@zhangsan` | 只看某人发的 |
| `in:@somechannel` | 只看某个聊天 |
| `has:image` | 只看带图片的 |
| `has:video` | 只看带视频的 |
| `before:2026-10-01` | 某天之前 |
| `after:2026-01-01` | 某天之后 |

中文不需要分词，直接搜词就行。

### 5.3 右栏面板

| 面板 | 用途 |
|---|---|
| 下载 | 媒体下载队列：进行中/排队/完成/失败，可暂停、可重试 |
| 统计 | 消息数、媒体数、会话数 |
| 通知 | 关键词 → Webhook / Bot 推送规则 |
| 点击 | 自动点击的出口配置与日志 |
| 账号 | 网页登录密码（不是 Telegram 密码） |

### 5.4 导出

右上角 **「⤓ 导出」**：

- **CSV**：表格，Excel 能直接打开
- **JSON**：结构化数据，给程序用

导出的是**当前视图**——你在「已删除」视图导出，拿到的就是被删内容。

## 六、常见问题

**Q：密钥丢了怎么办？**
找卖你软件的人，用你的设备码重新签一个。旧密钥作废不影响数据。

**Q：换手机了怎么办？**
新手机装好后，把**新设备码**发给对方，重新签一个密钥。旧手机上的归档不会自动同步过来，需要先把数据导出。

**Q：到期了会怎样？**
到期后打不开主界面，回到激活页。数据**不会删除**，续期后照常使用。
（永久密钥没有这个问题。）

**Q：没网能不能用？**
能看已经归档的内容。但收新消息、下载新媒体会中断，恢复网络后自动续上。
如果断网超过 12 小时，开 App 时会尝试联网核对一次授权；核对不上不影响使用，只有对方**明确撤销**你的授权才会锁上。

**Q：卸载 App 会丢数据吗？**
**会。** 归档数据存在 App 私有目录里，卸载即清空。
想保住数据：先在「存储」页确认备份，或者把要留的内容导出成 CSV/JSON。

**Q：占多少空间？**
文字几乎不占。媒体按实际大小算——一个 100MB 的视频就是 100MB。每个监控源加进来之前，想想值不值。
「▣ 存储」页能看实时的占用和手机剩余空间。

**Q：会被 Telegram 封号吗？**
软件用的是普通客户端协议，行为和官方客户端一致（不会群发、不会加好友、不会营销）。
**但任何第三方客户端都存在被限制的可能**，这是 Telegram 的规则，不是软件能保证的。
建议：用专门的小号做归档，不要用主号。

**Q：能同时归档几个账号？**
界面支持添加多个账号，但同一时间只有一个在跑。需要切换时在账号面板切换。

**Q：撤回的内容，对方能知道我保存了吗？**
不能。软件只是被动接收，不产生任何「已读」「已保存」的回执。

## 七、几条提醒

1. **让它一直在线。** 归档的价值在连续性，关掉的那段时间是空白。
   手机端请在系统设置里给它「允许后台运行 / 不受电量优化限制」，否则会被系统杀掉。
2. **建议用小号。** 归档号只做归档，不加好友、不发消息，风险最低。
3. **内容自己负责。** 这个软件只是把你本来就能看到的内容存了一份。
   存下来的东西怎么用、能不能传播，取决于内容和当地法律，与软件无关。
4. **密钥别外传。** 一把密钥绑一台机器，传出去也用不了，但会暴露你的设备码。
5. **定期导出重要内容。** 本地归档也会因为手机丢失、误删、存储损坏而丢。
   真正重要的东西，导出到电脑再存一份。

## 八、遇到问题怎么反馈

把这三样发给提供软件的人，能省掉一半沟通：

1. **设备码**（激活页上那 8 位）
2. **App 版本**（激活页底部 / 设置里）
3. **具体现象**：点了哪里、看到什么、期望什么。有截图最好

不要发你的 Telegram 验证码、两步验证密码、或 session 字符串给任何人——包括卖你软件的人。
