## 1. 这个软件是干什么的

一句话：**它用你自己的 Telegram 账号，把消息里的媒体文件下载到电脑上。**

有些频道、群组、机器人聊天里的图片和视频，在手机上有「保存」按钮也点不动，或者一次只能存一张。这个软件的做法是：你把那条消息的链接复制过来，它用你的账号去把原始文件拉下来，存到你指定的文件夹。

**能做什么**

- 下载单张图片、单个视频、单个文件
- 下载整组相册（一条消息里带 9 张图，一次全下来）
- 同时跑多个下载任务，可随时取消
- 记住你下过什么，失败可以重来

**不做什么**

- 不是网盘客户端，只做「从 Telegram 到你的电脑」
- 不下载别人的私密内容 —— 你能看到什么，它就能下什么
- 不需要密码托管，登录状态只保存在你自己电脑上

> **包里有三个程序，别慌**
> 平时只用 `Telegram下载器.exe` 一个就够了。另外两个是「归档面板」用的，属于进阶功能，第 7 节才讲。

## 2. 用之前要准备两样东西

这两样东西看起来麻烦，但只做一次，十分钟搞定。跳过这一步，软件打开后什么也下不了。

### 准备一：API ID 和 API Hash

这是 Telegram 给每个第三方客户端发的「身份证」。任何非官方的 Telegram 软件都需要它，属于正常流程。

1. **打开 `https://my.telegram.org`**
   用你平时登录 Telegram 的手机号登录。验证码会发到你 Telegram 客户端里的「Telegram」官方对话，不是短信。

2. **点「API development tools」**
   如果让你填表，随便填：
   - App title：`myapp`（随便写）
   - Short name：`myapp`（随便写，5 个字符以上）
   - Platform：选 `Desktop`

3. **记下两个值**
   - **App api_id** —— 一串数字，比如 `12345678`
   - **App api_hash** —— 一串 32 位的字母数字

> ⚠️ **这两个值等于你的账号钥匙，别给别人**
> 拿到它们的人可以冒充你这个客户端。不要发群里、不要截图、不要贴在网上。

> 💡 **my.telegram.org 打不开？**
> 这个网站在国内直连通常打不开。先开好代理软件（见准备二），再访问。

### 准备二：一个能连上 Telegram 的网络

软件本身不提供翻墙功能，它只是用你电脑现有的网络去连 Telegram。

- 如果你的电脑已经能正常打开 Telegram 桌面版 → **不用管，直接跳过**
- 如果连不上 → 你需要一个代理软件，并记下它的**本地端口**

| 你用的代理软件 | 常见的本地地址 |
|---|---|
| Clash / Clash Verge | `http://127.0.0.1:7890` |
| v2rayN | `socks5://127.0.0.1:10808` |
| Shadowsocks | `socks5://127.0.0.1:1080` |

## 3. 怎么把它装到电脑上

没有安装程序，不用点「下一步」。

1. **把压缩包解压出来**
   右键压缩包 →「全部解压缩」。建议解压到固定位置，比如 `D:\Telegram下载器\`。

2. **不要直接在压缩包里双击运行**
   必须先解压出来，在压缩包预览窗口里运行会失败。

3. **第一次双击会跳一个蓝色警告**
   见下面的说明，这是正常现象。

> ⚠️ **第一次打开会被 Windows 拦一下，这是正常的**
> 会看到蓝底白字窗口写着「Windows 已保护你的电脑」。
> 原因是这个软件没有买微软的代码签名证书（一年几千块），不是因为它有问题。
> **处理：** 点「更多信息」→ 点右下角出现的「仍要运行」。

### 压缩包里每个文件是干什么的

| 文件 | 作用 |
|---|---|
| **Telegram下载器.exe** | **主程序。平时就双击这个。** 打开是窗口界面，登录、粘贴链接、下载都在里面 |
| 启动归档面板.bat | 打开「归档面板」——浏览器里用的界面，批量翻看、搜索、整理已存消息。进阶功能 |
| 首次登录归档.bat | 归档面板第一次用之前，双击这个登录一次账号。**只做一次** |
| tdl.exe | 命令行版本，给懂技术的人用。普通用户不用管 |
| config.yaml | 归档面板的配置。普通用户不用改 |
| 使用说明.html / 先看这里.txt | 这份文档 + 三句话快速上手 |

> ⚠️ **这几个文件必须放在同一个文件夹里**
> `Telegram下载器.exe` 单独拿走还能用（设置存在别处），但 `启动归档面板.bat` 如果离开了 `tdl.exe` 和 `config.yaml`，点了会闪退。

## 4. 第一次使用（五步）

从双击到文件躺在你硬盘里，一共五步。第一次大概 5 分钟，之后每次只要第 4 步。

### 第 1 步：双击 `Telegram下载器.exe`

打开一个窗口，默认中文界面。顶部有三个标签：**下载**、**设置**、**关于**。

### 第 2 步：去「设置」页，填四样东西

这是唯一一次需要集中配置的地方，填完保存，以后不用再进。

| 字段 | 填什么 |
|---|---|
| **Telegram API ID** | 第 2 节拿到的 `api_id`，纯数字，比如 `12345678` |
| **Telegram API Hash** | 第 2 节拿到的 `api_hash`，32 位字母数字 |
| **下载目录** | 文件存哪。默认 `下载\Telegram Downloads`。建议改到空间大的盘，比如 `D:\Telegram` |
| **代理地址** | 网络连不上 Telegram 才填。能直连就留空 |

下面还有三个数字，**保持默认就好**：同时任务数 `2`、单任务下载线程数 `4`、DC 连接池大小 `8`。

填完点「**保存设置**」，会弹「保存成功」。

### 第 3 步：回「下载」页，点「登录」

流程和手机登录 Telegram 一样：

- 输入手机号，**要带国家码**，比如 `+8613800000000`
- 点「开始登录」
- Telegram 发一个 5 位验证码（发到你的 Telegram 客户端里，不是短信）→ 填进去
- 如果开了两步验证，还会让输两步验证密码

登录成功后顶部显示「**已登录**」。

> ✅ 登录状态会记住。关掉软件、重启电脑都不用重新登录。想换账号点「退出登录」。

### 第 4 步：复制一条 Telegram 消息链接，粘贴进来

**怎么拿到链接：**

- 手机 Telegram：长按那条消息 →「复制链接」
- 电脑 Telegram：右键那条消息 →「复制消息链接」

复制到的东西长这样：

```
https://t.me/c/1234567890/5678
https://t.me/channelname/123
```

粘进输入框，点「**添加下载**」。

### 第 5 步：看进度，等它下完

任务出现在下面的列表里，状态依次是：

`等待中` → `下载中` → `已完成`

- 下载中的任务**点一下可以取消**
- 失败的任务会显示原因
- 完成后提示「已保存到下载目录」

文件就在第 2 步设置的下载目录里。相册会整组下下来，不是只有一张。

> 💡 **下一次用的时候**：双击 → 直接粘贴链接 → 添加下载。设置和登录都不用再弄。

## 5. 界面逐块说明

软件一共三个页面，顶部标签切换。

### 「下载」页 —— 你 90% 的时间都在这里

| 位置 | 作用 |
|---|---|
| 顶部状态行 | 显示「已登录」或「未登录，请先登录 Telegram 账号」。旁边是登录/退出按钮 |
| 链接输入框 | 粘贴消息链接的地方 |
| 「添加下载」按钮 | 把链接丢进队列。格式不对会提示「请输入有效的 Telegram 消息链接」 |
| 任务列表 | 每条显示：链接、状态、进度、时间。点正在下载的任务 = 取消它 |
| 「移除全部」 | 清空任务记录。**只清记录，不删已下载的文件**。正在跑的任务会先被取消 |

> 💡 任务记录会保留。关掉软件再打开，之前的列表还在（「已取消」的是上次没跑完的）。

### 「设置」页 —— 只填一次

| 字段 | 说明 |
|---|---|
| 语言 | 简体中文 / English，切换立即生效 |
| Telegram API ID | 必填，纯数字 |
| Telegram API Hash | 必填，32 位字符串 |
| 下载目录 | 文件存哪。点「选择目录」可以浏览 |
| 代理地址 | 可选。`http://127.0.0.1:7890` 或 `socks5://127.0.0.1:1080` |
| 同时任务数 | 默认 2。同时下几个任务 |
| 单任务下载线程数 | 默认 4。一个任务用几个连接下 |
| DC 连接池大小 | 默认 8 |
| 「保存设置」 | 保存后提示「新启动的任务将使用新配置」。进行中的任务不受影响 |

> ⚠️ **三个数字不要乱调**
> 调太大（线程 16、并发 8）容易触发 Telegram 限流，反而更慢或直接失败。默认值够用。

### 「关于」页 —— 查版本、看更新

- 显示当前版本号和远程最新版本号
- 点「检查」查有没有新版
- 有新版给一个下载链接
- 下面写着官网和开源协议（AGPL-3.0）

## 6. 什么链接能下载

只认 Telegram 的公开消息链接，四种开头都行：

| 格式 | 例子 | 说明 |
|---|---|---|
| `https://t.me/…` | `https://t.me/channelname/123` | 公开频道/群组 |
| `https://t.me/c/…` | `https://t.me/c/1234567890/5678` | 私有频道/群组（最常见） |
| `https://telegram.me/…` | `https://telegram.me/xxx/123` | 旧式写法 |
| `http://` 开头 | `http://t.me/xxx/123` | 也支持 |

### 能下什么

- ✅ 图片（含原图）
- ✅ 视频（含大文件）
- ✅ 文档、压缩包、音频
- ✅ 整组相册
- ❌ 纯文字消息的「文字」不会单独存成文件，它本来就不是文件
- ❌ 你看不到的消息（没权限、已删除）也拿不到

### 什么情况下会失败

| 情况 | 说明 |
|---|---|
| 消息已删除 | 删了就是删了 |
| 你的账号不在那个群/频道 | 得先加进去 |
| 敏感内容被 Telegram 屏蔽 | 需要在 Telegram 设置里允许「敏感内容」 |
| 网络中断 | 关掉重来一次通常就好 |
| 文件太大 | 免费账号对单文件有大小限制 |

## 7. 进阶：归档面板（可选，不用也完全不影响）

桌面版是「下一份文件」的工具。归档面板是另一个东西：**它把你说过话的频道、收到的消息，全部存一份在你自己电脑上，然后给你一个网页界面去翻、去搜、去整理。**

适合：某个频道每天发几百条，想事后按关键词搜；或者想按发帖人、按日期、按类型筛。

> ⚠️ **先说清楚**
> 归档面板会把消息**内容**存到你的电脑上，包括图片视频的原始文件。数据量可能很大（几十 GB）。不需要这个功能就完全别碰。

### 开启步骤

**第 1 步：双击「首次登录归档.bat」**

会开一个黑色窗口，按提示走：

- 提示输入手机号 → 输 `+8613800000000` 这种格式，回车
- 提示输入验证码 → 输 Telegram 收到的码，回车
- 如果有两步验证 → 输密码，回车

> 💡 **为什么要单独登录一次？**
> 归档面板用的登录状态和桌面版是**分开存**的。你在桌面版登录过，归档面板还是要单独登一次。这是两个独立存储位置，不是 bug。

**第 2 步：双击「启动归档面板.bat」**

- 弹一个黑色窗口，显示「归档面板正在启动」
- 3 秒后浏览器自动打开 `http://127.0.0.1:8091`
- 没自动打开就手工把这个地址复制到浏览器

**第 3 步：在网页里添加要监控的频道/群**

进入「监控」→ 添加 → 填 `@频道用户名` 或数字 chat-id → 它开始拉历史消息，然后持续接收新消息。

**第 4 步：用左边导航浏览**

| 导航项 | 看到什么 |
|---|---|
| 消息 | 所有消息的时间线 |
| 图片 / 视频 / 文件 | 按类型筛，同一文件重复出现的折叠成一张卡 |
| 链接 | 消息里出现过的所有网址 |
| 已删除 | 对方删了、但你本地还留着的消息 |
| 编辑记录 | 消息被改过的历史版本 |
| 编号 | 按「收到顺序」的流水号，每个媒体一个号，永不复用 |
| 材料 | 整理后的内容层，同一条内容在多个频道出现只算一份 |
| 存储 | 占了多少空间，哪些能清理 |
| 监控 | 添加/删除要归档的频道 |

### 三个使用要点

| 要点 | 说明 |
|---|---|
| 黑色窗口不能关 | 那个窗口就是服务本身。关掉 = 面板停止。要再用就再双击一次 bat |
| 只有本机能访问 | 默认只监听 `127.0.0.1`，局域网其他电脑也访问不到。这是有意的安全设计 |
| 管理功能需要 config.yaml | 包里已配好。如果只让看不让加监控，说明 `config.yaml` 没和 `tdl.exe` 放在一起 |

## 8. 常见问题（12 条）

### Q1. 双击没反应，或者窗口一闪就没了

三个可能，按顺序排：

1. 你是在**压缩包里**直接双击的 → 先解压出来再运行
2. 被 Windows Defender 或 360 拦了 → 打开杀毒软件的「隔离区」，恢复并加白名单
3. 缺系统组件 → 这个版本需要 **Windows 10 或更高**，Win7/8 跑不了

### Q2. 提示「请先在设置中填写 Telegram API ID 和 API Hash」

去「设置」页填上第 2 节拿到的两个值，点「保存设置」，然后**回到下载页重新点一次添加下载**（不会自动重试）。

### Q3. 登录时收不到验证码

验证码不发短信，**发到你 Telegram 客户端的「Telegram」官方对话里**。

如果手机上也没收到，等 60 秒后重试；连续失败多次会被限流，要等十几分钟。

### Q4. 一直卡在「正在检查登录状态…」

99% 是网络问题。

1. 先在「设置」里填代理地址（`http://127.0.0.1:7890`）
2. 确认代理软件正在运行，并开了「允许局域网连接」
3. 保存设置后**关掉软件重新打开**（代理只在启动时读）

### Q5. 下载很慢，或者下到一半失败

1. 网络本身慢 → 换个节点
2. 同时下太多 → 把「同时任务数」调回 2
3. 大文件在高峰期慢是正常的，Telegram 对免费账号有带宽限制
4. 失败了就删掉那条记录重新添加

### Q6. 下载的文件在哪？找不到

打开软件 →「设置」→ 看「下载目录」那一栏。

默认是 `C:\Users\你的用户名\Downloads\Telegram Downloads`。

### Q7. 相册只下了一张

1. 检查是不是还在「下载中」，大相册需要时间
2. 有些相册里的部分图片在服务器端已失效，那种拿不到
3. 把链接重新添加一次，通常会补齐

### Q8. 杀毒软件报毒 / 提示有木马

这是**没有代码签名**的程序常见的误报。原因：

- 程序是 Go 编译的独立 exe，体积大（60MB+），行为像「加壳程序」
- 没有买微软/360 的白名单
- 它会主动连接 Telegram 服务器

处理：加白名单 / 信任。不放心的话，这个项目是开源的（AGPL-3.0），可以让懂技术的人看源码。

### Q9. 提示「Current database is used by another process」

有两个程序同时用了同一份数据：

1. 开了两个 `tdl.exe` 窗口（双击了两次启动 bat）
2. 归档面板正在跑，同时你又开了别的归档命令

关掉多余的那个。

### Q10. 归档面板打开是空白页

1. 确认黑色窗口还在，里面有没有红色报错
2. 地址是不是 `127.0.0.1:8091`（不是 8080，不是 https）
3. 端口被占了 → 关掉其他程序，或改 bat 里的端口号
4. 浏览器缓存 → `Ctrl+Shift+R` 强制刷新

### Q11. 归档面板里没有数据，或者显示「只能浏览」

两种不同的情况：

- **没有数据** → 你没添加监控。进「监控」页添加频道/群
- **只能浏览不能管理** → `config.yaml` 没被读到。确认它和 `tdl.exe` 在同一文件夹，并且通过 bat 启动

### Q12. 想换一个 Telegram 账号

- **桌面版**：点「退出登录」→ 确认 → 重新登录新账号
- **归档面板**：重新双击「首次登录归档.bat」，登录新账号会覆盖旧的

注意：两者要**分别**换。

## 9. 文件存在哪，怎么彻底删掉

### 三个位置

| 存什么 | 位置 |
|---|---|
| 下载的文件 | 你设置的下载目录，默认 `C:\Users\你的用户名\Downloads\Telegram Downloads` |
| 桌面版的设置和登录状态 | `C:\Users\你的用户名\AppData\Roaming\telegram-download-bot\` |
| 归档面板的数据 | `C:\Users\你的用户名\.tdl\archive\` |

> 💡 **快速打开**：按 `Win+R`，把路径粘进去（`%APPDATA%\telegram-download-bot` 也行），回车。

### 彻底删干净（三步）

1. 删掉整个程序文件夹
2. 删掉 `%APPDATA%\telegram-download-bot` —— 登录状态，不删的话下次装回来还是登录着的
3. 如果用过归档面板，再删掉 `%USERPROFILE%\.tdl` —— 里面是归档的图片视频，可能占几十 GB

> ⚠️ **不删第 2 步的后果**
> 软件是绿色版，没有注册表项，不装服务。但登录状态留在 `%APPDATA%` 里。电脑要转手务必删掉，否则拿到这台电脑的人可以直接用你的 Telegram 账号。

### 只清归档数据、保留设置

删掉 `%USERPROFILE%\.tdl\archive\objects` 这个文件夹，能回收绝大部分空间。消息记录还在，只是文件没了。

## 10. 出问题了怎么反馈

给提供软件的人发这三样：

1. **版本号** —— 软件里「关于」页显示的那一行
2. **截图** —— 报错窗口的完整文字，别只截「出错了」三个字
3. **日志文件** —— `C:\Users\你的用户名\AppData\Roaming\telegram-download-bot\desktop.log`
   归档面板的问题则是黑色窗口里的红色文字

> ⚠️ **发之前把这两个打码**：`api_hash`（32 位那串）、手机号。这两个泄露了等于账号泄露。
