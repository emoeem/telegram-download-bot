1这个软件是干什么的

一句话：它用你自己的 Telegram 账号，把消息里的媒体文件下载到电脑上。

有些频道、群组、机器人聊天里的图片和视频，在手机上有「保存」按钮也点不动，或者一次只能存一张。这个软件的做法是：你把那条消息的链接复制过来，它用你的账号去把原始文件拉下来，存到你指定的文件夹。

它能做什么

  • 下载单张图片、单个视频、单个文件
  • 下载整组相册（一条消息里带 9 张图，一次全下来）
  • 同时跑多个下载任务，可随时取消
  • 记住你下过什么，失败可以重来

它不做什么

  • 它不是网盘客户端，不会把你的文件传到别的地方，只做「从 Telegram 到你的电脑」
  • 它不下载别人的私密内容，你能看到什么，它就能下什么，看不到的它也拿不到
  • 不需要密码托管，登录状态只保存在你自己电脑上
包里有三个程序，别慌 平时只用 Telegram下载器.exe 一个就够了。另外两个是「归档面板」用的，属于进阶功能，第 7 节才讲。第 3 节有每个文件的说明。

2用之前要准备两样东西

这两样东西看起来麻烦，但只做一次，十分钟搞定。跳过这一步，软件打开后什么也下不了。

准备一：API ID 和 API Hash

这是 Telegram 给每个第三方客户端发的「身份证」。任何非官方的 Telegram 软件都需要它，属于正常流程。

  1. 打开 https://my.telegram.org 用你平时登录 Telegram 的手机号登录。验证码会发到你 Telegram 客户端里的「Telegram」官方对话，不是短信。
  2. 点「API development tools」 进去后如果让你填表，随便填：
    • App title：myapp（随便写）
    • Short name：myapp（随便写，5 个字符以上）
    • Platform：选 Desktop
    提交。
  3. 记下两个值 页面上会出现：
    • App api_id —— 一串数字，比如 12345678
    • App api_hash —— 一串 32 位的字母数字，比如 a1b2c3d4e5f6...
    把这两个复制到记事本里，等下要用。
这两个值等于你的账号钥匙，别给别人 拿到 api_id 和 api_hash 的人可以冒充你这个客户端。不要发到群里、不要截图发朋友圈、不要贴在网上。
my.telegram.org 打不开？ 这个网站在国内直连通常打不开。先开好你的代理软件（下一节会讲），再访问。如果实在拿不到，可以找提供软件的人要一份「公共凭据」，但那样所有用这份凭据的人共享额度，稳定性差一些。

准备二：一个能连上 Telegram 的网络

软件本身不提供翻墙功能，它只是用你电脑现有的网络去连 Telegram。所以：

  • 如果你的电脑已经能正常打开 Telegram 桌面版 → 不用管，直接跳过
  • 如果连不上 → 你需要一个代理软件，并记下它的本地端口
你用的代理软件常见的本地地址
Clash / Clash Vergehttp://127.0.0.1:7890
v2rayNsocks5://127.0.0.1:10808
Shadowsockssocks5://127.0.0.1:1080

不确定的话，打开你的代理软件看「设置 → 本地端口」，或者「局域网连接」那一栏。

3怎么把它装到电脑上

没有安装程序，不用点「下一步」。

  1. 把压缩包解压出来 右键压缩包 →「全部解压缩」。建议解压到一个固定位置，比如 D:\Telegram下载器\。
  2. 不要直接在压缩包里双击运行 必须先把文件解压出来，在压缩包预览窗口里运行会失败。
  3. 第一次双击会跳一个蓝色警告 见下面的说明，这是正常现象。
第一次打开会被 Windows 拦一下，这是正常的

会看到一个蓝底白字的窗口，写着「Windows 已保护你的电脑」。

原因是这个软件没有花钱买微软的代码签名证书（一年几千块），不是因为它有问题。

处理方法：点窗口里的「更多信息」→ 再点右下角出现的「仍要运行」。

4第一次使用（五步）

从双击到文件躺在你硬盘里，一共五步。第一次大概 5 分钟，之后每次只要第 4 步。

  1. 双击 Telegram下载器.exe 会打开一个窗口，默认是中文界面。顶部有三个标签：下载、设置、关于。
  2. 先去「设置」页，填四样东西 这是唯一一次需要集中配置的地方，填完保存，以后不用再进。
    字段填什么
    Telegram API ID 第 2 节拿到的 api_id，纯数字，比如 12345678
    Telegram API Hash 第 2 节拿到的 api_hash，32 位字母数字
    下载目录 文件存哪。默认是 下载\Telegram Downloads。点「选择目录」可以改，建议改到空间大的盘，比如 D:\Telegram
    代理地址 网络连不上 Telegram 才填，格式见第 2 节。能直连就留空

    下面还有三个数字，保持默认就好：同时任务数 2、单任务下载线程数 4、DC 连接池大小 8。电脑好、网络快可以往上调，调太高反而容易断。

    填完点「保存设置」，会弹「保存成功」。
  3. 回「下载」页，点「登录」 流程和你在手机上登录 Telegram 一模一样：
    • 输入手机号，要带国家码，比如 +8613800000000
    • 点「开始登录」
    • Telegram 会给你发一个 5 位验证码（发到你的 Telegram 客户端里，不是短信）→ 填进去
    • 如果你开了两步验证，还会让你输两步验证密码
    登录成功后，页面顶部会显示「已登录」。
    登录状态会记住 关掉软件、重启电脑都不用重新登录。想换账号，点「退出登录」。
  4. 复制一条 Telegram 消息链接，粘贴进来

    怎么拿到链接：

    • 手机 Telegram：长按那条消息 →「复制链接」
    • 电脑 Telegram：右键那条消息 →「复制消息链接」
    复制到的东西长这样：
    https://t.me/c/1234567890/5678 或 https://t.me/channelname/123

    粘进输入框，点「添加下载」。

  5. 看进度，等它下完 任务会出现在下面的列表里，状态依次是： 等待中 → 下载中 → 已完成
    • 下载中的任务点一下可以取消
    • 失败的任务会显示原因，通常是网络断了或链接失效
    • 完成后右上角会提示「已保存到下载目录」
    文件就在你第 2 步设置的下载目录里。相册会整组下下来，不是只有一张。
下一次用的时候 双击 → 直接粘贴链接 → 添加下载。设置和登录都不用再弄。

5界面逐块说明

软件一共三个页面，顶部标签切换。

「下载」页 —— 你 90% 的时间都在这里

位置作用
顶部状态行 显示 已登录 或「未登录，请先登录 Telegram 账号」。旁边是「登录 / 退出登录」按钮。
链接输入框 粘贴消息链接的地方。灰字提示是示例格式。
「添加下载」按钮 把链接丢进队列。链接格式不对会立刻提示「请输入有效的 Telegram 消息链接」。
任务列表 每条任务显示：链接、状态、进度、时间。点正在下载的任务 = 取消它。旁边的按钮可以移除单条记录。
任务列表下方小字 说明任务会按设置的并发数自动跑，点下载中的任务可以取消。
「移除全部」 清空任务记录。只清记录，不删已下载的文件。正在跑的任务会先被取消。
任务记录会保留 关掉软件再打开，之前的任务列表还在（显示为「已取消」的那些是上次没跑完的）。这是故意的，方便你看下过什么。

「设置」页 —— 只填一次

字段说明
语言简体中文 / English。切换后立即生效。
Telegram API ID必填，纯数字。
Telegram API Hash必填，32 位字符串。
下载目录文件存哪。点右边「选择目录」可以浏览文件夹。
代理地址可选。格式 http://127.0.0.1:7890 或 socks5://127.0.0.1:1080。
同时任务数默认 2。同时下几个任务。
单任务下载线程数默认 4。一个任务用几个连接下。
DC 连接池大小默认 8。Telegram 有多个数据中心，池子越大切换越顺。
「保存设置」保存后提示「设置已保存；新启动的任务将使用新配置」。已在进行中的任务不受影响。
三个数字不要乱调 调太大（比如线程 16、并发 8）容易触发 Telegram 限流，反而更慢或者直接失败。默认值已经调过了，够用。

「关于」页 —— 查版本、看更新

  • 显示当前版本号和远程最新版本号
  • 点「检查」可以查有没有新版
  • 有新版会给一个「前往 Release 下载最新版本」的链接

6什么链接能下载

只认 Telegram 的公开消息链接，四种开头都行：

格式例子说明
https://t.me/… https://t.me/channelname/123 公开频道/群组
https://t.me/c/… https://t.me/c/1234567890/5678 私有频道/群组（最常见）
https://telegram.me/… https://telegram.me/xxx/123 旧式写法，同样支持
http:// 开头 http://t.me/xxx/123 也支持

能下什么

  • ✅ 图片（含原图）
  • ✅ 视频（含大文件）
  • ✅ 文档、压缩包、音频
  • ✅ 整组相册（一条消息里的多张图）
  • ❌ 纯文字消息的「文字」不会单独存成文件，它本来就不是文件
  • ❌ 你看不到的消息（没权限、已删除）也拿不到

什么情况下会失败

  • 链接指向的消息已删除 → 提示失败，删了就是删了
  • 你的账号不在那个群/频道里 → 拿不到，得先加进去
  • 敏感内容被 Telegram 屏蔽 → 需要在 Telegram 设置里允许「敏感内容」，这是账号级别的设置
  • 网络中断 → 关掉重来一次通常就好
  • 文件太大 → 免费账号对单个文件有大小限制，超了会失败

7进阶：归档面板（可选，不用也完全不影响）

桌面版是「下一份文件」的工具。归档面板是另一个东西：它把你说过话的频道、收到的消息，全部存一份在你自己电脑上，然后给你一个网页界面去翻、去搜、去整理。

适合的场景：某个频道每天发几百条，你想事后按关键词搜；或者想按发帖人、按日期、按类型（图片/视频/文件）筛。

先把话说清楚 归档面板会把消息内容存到你的电脑上，包括图片视频的原始文件。数据量可能很大（几十 GB）。不需要这个功能就完全别碰，第 1 到 6 节已经覆盖了下载需求。

开启步骤

  1. 双击「首次登录归档.bat」 会开一个黑色窗口，按提示走：
    • 提示输入手机号 → 输 +8613800000000 这种格式，回车
    • 提示输入验证码 → 输 Telegram 收到的码，回车
    • 如果有两步验证 → 输密码，回车
    为什么要单独登录一次？ 归档面板用的登录状态和桌面版是分开存的。你在桌面版登录过，归档面板还是要单独登一次。这是两个独立的存储位置，不是 bug。
  2. 双击「启动归档面板.bat」
    • 会弹一个黑色窗口，显示「归档面板正在启动」
    • 3 秒后浏览器自动打开 http://127.0.0.1:8091
    • 如果浏览器没自动打开，手工把这个地址复制到浏览器地址栏
  3. 在网页里添加要监控的频道/群 进入「监控」→ 添加 → 填 @频道用户名 或数字 chat-id → 它会开始把历史消息拉下来，然后持续接收新消息。
  4. 用左边导航浏览
    导航项看到什么
    消息所有消息的时间线
    图片 / 视频 / 文件按类型筛，同一文件重复出现的会折叠成一张卡
    链接消息里出现过的所有网址
    已删除对方删了、但你本地还留着的消息
    编辑记录消息被改过的历史版本
    编号按「收到顺序」的流水号，每个媒体一个号，永不复用
    材料整理后的内容层，同一条内容在多个频道出现只算一份
    存储占了多少空间，哪些能清理
    监控添加/删除要归档的频道

三个使用要点

要点说明
黑色窗口不能关 那个窗口就是服务本身。关掉窗口 = 面板停止。想继续用就再双击一次 bat。
只有本机能访问 默认只监听 127.0.0.1，同一局域网的其他电脑也访问不到。这是有意的安全设计，不用改。

8常见问题（12 条）

双击没反应，或者窗口一闪就没了
三个可能，按顺序排：
① 你是在压缩包里直接双击的 → 先解压出来再运行
② 被 Windows Defender 或 360 拦了 → 打开杀毒软件的「隔离区」，把文件恢复并加白名单
③ 缺系统组件 → 这个版本需要 Windows 10 或更高，Win7/8 跑不了
提示「请先在设置中填写 Telegram API ID 和 API Hash」
去「设置」页填上第 2 节拿到的两个值，点「保存设置」，然后回到下载页重新点一次添加下载（不会自动重试）。
登录时收不到验证码
验证码不发短信，发到你 Telegram 客户端的「Telegram」官方对话里。打开手机上的 Telegram 看一眼。
如果手机上也没收到，等 60 秒后重试；连续失败多次会被限流，这时候要等十几分钟。
一直卡在「正在检查登录状态…」或者登录转圈
99% 是网络问题。Telegram 连不上。
① 先在「设置」里填代理地址（格式 http://127.0.0.1:7890）
② 确认你的代理软件正在运行，并且开了「允许局域网连接」
③ 保存设置后关掉软件重新打开（代理只在启动时读）
下载很慢，或者下到一半失败
先别急着调参数。按这个顺序排查：
① 网络本身慢 → 换个节点试试
② 同时下太多 → 把「同时任务数」调回 2
③ 大文件在高峰期慢是正常的，Telegram 对免费账号有带宽限制
④ 失败了就删掉那条记录重新添加，会从断点继续
下载的文件在哪？找不到
打开软件 →「设置」→ 看「下载目录」那一栏写的是什么路径。
默认是 C:\Users\你的用户名\Downloads\Telegram Downloads。
也可以在「下载」页，任务完成后点那条任务，通常会显示保存位置。
相册只下了一张，其他几张没下来
正常情况会自动整组下。如果只下了一张：
① 检查是不是任务还在「下载中」，大相册需要时间
② 有些相册里的部分图片在服务器端已经失效，那种拿不到
③ 把链接重新添加一次，通常会补齐缺的那几张
杀毒软件报毒 / 提示有木马
这是没有代码签名的程序常见的误报。原因：
· 程序是用 Go 编译的独立 exe，体积大（60MB+），行为像「加壳程序」
· 没有花钱买微软/360 的白名单
· 它会主动连接 Telegram 服务器
处理：在杀毒软件里把这个文件加白名单 / 信任。如果你不放心，这个项目是开源的（AGPL-3.0），可以让懂技术的人看源码。
提示「Current database is used by another process」
有两个程序同时用了同一份数据。检查是不是：
① 开了两个 tdl.exe 窗口（比如双击了两次启动 bat）
② 归档面板正在跑，同时你又开了别的归档命令
关掉多余的那个就好。
归档面板打开是空白页 / 转圈不出来
① 确认黑色窗口还在，里面有没有红色的报错
② 地址是不是 127.0.0.1:8091（不是 8080，不是 https）
③ 端口被占了 → 关掉其他程序，或者改 bat 里的端口号
④ 浏览器缓存 → 按 Ctrl+Shift+R 强制刷新
归档面板里没有数据，或者显示「只能浏览」
两种不同的情况：
没有数据 → 你没添加监控。进「监控」页添加频道/群。
只能浏览不能管理 → config.yaml 没被读到。确认它和 tdl.exe 在同一个文件夹，并且是通过 bat 启动的（bat 会自动切到所在目录）。
想换一个 Telegram 账号
桌面版：点「退出登录」→ 会提示「退出会删除此电脑上保存的 Telegram 登录状态」→ 确认 → 重新登录新账号。
归档面板：重新双击「首次登录归档.bat」，登录新账号会覆盖旧的。
注意：两者要分别换。

9文件存在哪，怎么彻底删掉

三个位置，记一下

存什么位置（把「你的用户名」换成实际的）
下载的文件 你设置里指定的下载目录，默认 C:\Users\你的用户名\Downloads\Telegram Downloads
桌面版的设置和登录状态 C:\Users\你的用户名\AppData\Roaming\telegram-download-bot\
归档面板的数据（消息、图片、视频） C:\Users\你的用户名\.tdl\archive\
怎么快速打开这些文件夹 按 Win+R，把上面的路径粘进去（%APPDATA%\telegram-download-bot 也行），回车。

彻底删干净（三步）

  1. 删掉整个程序文件夹（你解压出来的那个）
  2. 删掉 %APPDATA%\telegram-download-bot —— 这是登录状态，不删的话下次装回来还是登录着的
  3. 如果用过归档面板，再删掉 %USERPROFILE%\.tdl —— 这里面是归档的图片视频，可能占几十 GB
不删第 2 步的后果 软件是绿色版，没有注册表项，也不装服务。但登录状态留在 %APPDATA% 里。如果电脑要转手，务必删掉，否则拿到这台电脑的人可以直接用你的 Telegram 账号。

怎么只清归档数据、保留设置

删掉 %USERPROFILE%\.tdl\archive\objects 这个文件夹，能回收绝大部分空间（图片视频都在这）。消息记录还在，只是文件没了。

10出问题了怎么反馈

给提供软件的人发这三样，能省掉一半来回：

  1. 版本号 软件里「关于」页显示的那一行。
  2. 截图 报错的那个窗口，把完整文字截进去。别只截「出错了」三个字。
  3. 日志文件 C:\Users\你的用户名\AppData\Roaming\telegram-download-bot\desktop.log
    归档面板的问题则是黑色窗口里的红色文字。
发之前把这两个东西打码 · api_hash（32 位那串）
· 手机号（截图里如果有）
这两个泄露了等于账号泄露。
