========================================================
  Telegram 下载器 · Windows 版
========================================================

先看「使用说明.html」（双击打开，图文说明）。

--------------------------------------------------------
  三个文件分别是干什么的
--------------------------------------------------------

Telegram下载器.exe
    桌面版主程序。双击就能用，有窗口界面。
    → 平时用这个。

启动归档面板.bat
    打开「归档面板」这个网页版工具（浏览器里的界面）。
    → 需要批量浏览、搜索、整理已归档的消息时用。

首次登录归档.bat
    归档面板第一次使用前，要先双击这个登录一次账号。
    → 只做一次，以后再也不用。

tdl.exe
    命令行工具，给懂技术的人用的。
    → 普通用户不用管它。

--------------------------------------------------------
  三句话上手
--------------------------------------------------------

1. 双击「Telegram下载器.exe」，进「设置」填 API ID 和 API Hash
2. 回「下载」页，把 Telegram 消息链接粘贴进去，点「添加下载」
3. 文件下到「下载\Telegram Downloads」文件夹

--------------------------------------------------------
  遇到问题
--------------------------------------------------------

先看「使用说明.html」最后一节「常见问题」，
里面写了 12 种最常遇到的情况和处理办法。

如果还是不行，把这两个信息发给提供软件的人：
  · 软件里「关于」页显示的版本号
  · 出错时的截图（或 %APPDATA%\TelegramDownloader\desktop.log）
