❓ 使用说明

快速开始

  1. 点击顶栏账号芯片，用手机 Telegram 设置 → 设备 → 链接桌面设备 扫码登录（如开启了两步验证，需再输入云密码）。
  2. 左侧 Monitored sources → 添加源，填入 @username 或 t.me 链接，保存后自动回填历史消息。
  3. 归档由 serve 进程实时进行（含每 10 分钟巡检补漏与媒体下载）；也可另开终端运行 tdl archive run 获得更强的长驻监控。
  4. 顶部搜索框支持 from:@user / in:@channel / has:image / before:2026-10-01 等语法。

CLI 命令参考

  • tdl archive login [--qr] — 终端登录（验证码或扫码）
  • tdl archive monitor add @channel --limit 1000 --since 2026-01-01
  • tdl archive run — 长驻实时监听 + 巡检 + 媒体下载
  • tdl archive sync @channel — 手动补洞
  • tdl archive search "关键词" / stats / doctor
  • tdl archive media pending|retry — 媒体任务排查
  • tdl archive notify add/list/test/log — 关键词通知规则（Webhook / Bot API）

通知规则

  • 右侧「通知」面板或 CLI 可创建规则：匹配关键词的实时新消息会推送到 Webhook（JSON POST）或 Telegram Bot API。
  • 历史回填不触发通知；每条规则限速 20 条/分钟；Bot Token 只写入不回显。

注意事项

  • 归档使用你的 用户账号（MTProto），只能归档你有权限查看的内容。
  • 数据位于 ~/.tdl/archive/（SQLite + 内容寻址媒体对象）。
  • serve 默认监听 127.0.0.1；对外暴露请务必加 --auth-basic user:pass。
  • 消息删除为软删除、编辑保留全部版本，可在 Deleted / Edits 视图查看。
